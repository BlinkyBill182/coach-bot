# מאמן כושר אישי בטלגרם

בוט שרץ על שרת משלכם ומנהל לכם את האימונים והתזונה. אתם מדברים איתו, והוא רושם, מחשב ומזכיר. הוא גם כותב ראשון, בלי לחכות שתפנו אליו.

הקוד הוא תבנית להרצה אישית: כל עותק משרת אדם אחד, עם המפתחות והנתונים שלו.

## מה הוא עושה

- **רישום בשיחה:** הודעה, תמונה של הצלחת או הודעה קולית. הוא מעריך מאקרו ורושם.
- **מאזן את היום:** אחרי כל ארוחה הוא מעדכן את הארוחות שנשארו כדי להגיע ליעד.
- **תזכורות:** שקילה, ארוחות עם כפתור "אכלתי", ציוד לפני יציאה, ותוכנית למחר כל ערב ב-21:30.
- **תכנון סביב היומן:** מזיז את האימון לחלון פנוי, ומתאים ארוחות לימים מחוץ לבית.
- **קניות ובישול:** רשימת קניות בערב לפני תחילת השבוע, ותזכורת ערב לפני יום בישול.
- **אימון:** משימה עם משקל יעד, מעקב אחרי שיאים ורצפים, וסיכום שבועי לפי ממוצע המשקל.
- **מעקב בתוך טלגרם:** דף עם לוח שנה, מאקרו, משקל ואימונים.
- **שינויים בשיחה:** יעדים, ימי אימון, תרגילים ותפריט. כל שינוי קבוע מוצג קודם, ונכנס רק אחרי שתאשרו.

ההתאמה הראשונה מגיעה משאלון של 9 שאלות בתוך טלגרם (`/onboarding`).

## ממה הוא בנוי

Claude עם 36 כלים, ידע אימון ותזונה עם מקורות (`.claude/skills/muscle-coach`), Python ו-SQLite, ב-Docker מאחורי Traefik, עם בדיקות ו-GitHub Actions להעלאה.

## איך מתקינים

[הוראות ההתקנה](bot/SETUP.md). בסיס חובה: טלגרם, מפתח של Claude ושרת. יומן Google, הודעות קוליות, Wolt וזמני נסיעה הם תוספות.

**יוצרים עותק פרטי עם Use this template, ולא Fork.** Fork של ריפו ציבורי הוא ציבורי.

## איך מתאימים אותו לעצמכם

| מה | איפה |
|---|---|
| יעדים, ימי אימון, תרגילים, תבנית ארוחות | אומרים לבוט בטלגרם |
| דברים שלא אוכלים, העדפות, שגרה | השאלון, או פשוט אומרים לבוט |
| חדר כושר, שעות פתיחה, ימי בישול, רשימת קניות | `bot/coach/personal.py` |
| איך המאמן חושב ומדבר | `.claude/skills/muscle-coach/SKILL.md` |

הפרומפט הזה עובד טוב ב-Claude Code, בתיקיית הריפו:

```text
קרא את CLAUDE.md ואת .claude/skills/muscle-coach/SKILL.md.
שאל אותי שאלה אחת בכל פעם על השגרה שלי: איפה אני מתאמן ובאילו שעות, באילו ימים אני מבשל, מה אני קונה ומה אני לא אוכל.
אחר כך עדכן את bot/coach/personal.py ואת SKILL.md לפי התשובות, הרץ את הבדיקות והראה לי מה השתנה.
```

## מה כדאי לדעת

- הבוט מדבר עברית, פונה בלשון זכר, ועובד לפי שעון ישראל.
- קריאטין נמצא ברשימת הבדיקה של סגירת היום. מי שלא לוקח אותו צריך להוריד אותו מ-`domain.py` ומ-`tracker.html`.
- השאלון מעריך שריפה בנוסחה, עם טעות של בערך 10%. אחרי כמה שבועות מגמת המשקל מדויקת יותר.
- הודעות, תמונות ונתונים שאתם שולחים עוברים דרך ה-API של Anthropic כדי לקבל תשובה.
- נתוני הבריאות שלכם נשמרים על השרת שלכם. לא שומרים גיבויים בריפו ציבורי.
- זה כלי אימון ולא ייעוץ רפואי או תזונתי. עם מצב רפואי, הריון, הפרעת אכילה או כאב מתמשך פונים לרופא לפני שמשנים תזונה או אימונים.
